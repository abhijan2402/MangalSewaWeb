# MangalSewa Privacy Page

A responsive React page presenting the MangalSewa privacy policy. The page includes in-page section navigation and a print-friendly layout.

## Run locally

```sh
npm install
npm run dev
```

## Validate and build

```sh
npm run lint
npm run build
```

The policy text is a general draft. Confirm it matches MangalSewa's actual data practices, service providers, and applicable legal requirements before publishing.
